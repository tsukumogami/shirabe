# widgets

Eval fixture repository for /plan. It selects plan version v2 with the
`## Plan Version:` header, so /plan writes a step plan unless the command line
says otherwise. It also asks for a tracking level of `issues`, which a step
plan does not apply: it files no issues.

## Repo Visibility: Public

## Planning Context: Tactical

## Plan Version: v2

## Tracking Level: issues
