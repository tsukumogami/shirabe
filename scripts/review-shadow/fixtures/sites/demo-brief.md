# BRIEF: demo

## Status

Draft

## Problem Statement

Authors keep several drafts open at once and can't tell which ones a
reviewer has read.

They end up asking in chat.

## User Outcome

An author opens the list and sees which drafts still need a reader.

## User Journeys

### The author checks the list

An author with three open drafts opens the list before standup.

They see one draft marked unread and ask for a reader.

### The reviewer picks up work

A reviewer with a free hour opens the list and takes the oldest unread draft.

## Scope Boundary

**IN:** the list. **OUT:** notifications.
